The Go application should use Uber Fx for dependency injection and to manage the http handler.  The server should also use Chi server and RESTful path parameters for latitude and longitude.  The server handler shall call an interface implemented with the National Weather service api.  The interface call should be with a pointer using variables for path and urls that are initiated from env variables using  caarlos0/env.  The interface should have calls to apply the handler for th enational weather service, and to initialize the service. Errors from national weather srvice api should be handeld with a 400 response.  Lat and long should be limited to 4 decimal places.  Validation of lat and long should return the appropriate 400 error.  The weather service api requires a User-Agent header.  Use the client request user agent if available.  If no User-Agent is in the client request use a default user agent from an environment variable. Ensure logging of all failed requests for debugging purposes.
